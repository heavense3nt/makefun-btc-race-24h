Range Rider: a slow 480-bar range-trading bot for Coinbase Wrapped BTC (cbBTC) vs USDC. It buys with all cash at the bottom 15% of the trailing 8-hour range, sells the whole position at the top 5%, with an 80 bps trailing stop as protection. Net PnL +30.82 USDC (+3.08%) on the dev window, 5 trades, 0.72% max drawdown.

## Run it

```sh
node main.ts
```
